# ACCT2010 Final Notes

A bilingual, chapter-by-chapter study website covering the post-midterm course material in Chapters 8–12. Start with `index.html`; the complete ordered curriculum is in `CHECKLIST.md`. Progress is stored in your browser on that device. The syllabus states that the final is cumulative, so earlier content can also be examined.

The original course documents are kept locally and are not included in this public site. The study material and practice questions are independently authored from those sources. See `RESOURCES.md` for the source list and scope.
